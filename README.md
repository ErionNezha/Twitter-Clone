# 🐦 MiniTwitter

Posto mendimet e tua, bëj like dhe retweet — gjithçka ruhet në shfletuesin tënd.

Klon elegant i Twitter-it që funksionon tërësisht në browser — pa server, pa llogari.

## ✨ Veçori

- ✍️ Kompozitor me limit 280 karaktere + unazë progresi (skuqet afër limitit)
- ❤️ Like me animacion zemre + numërues
- 🔁 Retweet toggle (jeshile kur aktiv)
- 💬 Numërues përgjigjesh
- 🗑️ Fshirje postimi
- 🕐 Koha relative ("tani", "para 5 min", "para 2 orë")
- 👤 Avatar me iniciale + gradient unik sipas emrit
- 💾 Gjithçka ruhet në localStorage
- 📱 Plotësisht responsive
